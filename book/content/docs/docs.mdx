RespKit adalah pustaka Go untuk membentuk response HTTP yang konsisten, menerjemahkan pesan error, dan memetakan error Go ke status HTTP yang aman.

```go
resp.OK(ctx, data)
resp.Created(ctx, data, resp.Location("/users/123"))
resp.NoContent(ctx)
resp.Fail(ctx, err)
resp.NotFound(ctx)
```

Satu API dapat dipakai dengan `net/http`, Gin, Echo v4/v5, Fiber v2/v3, Chi, Gorilla/mux, dan Beego v2.

## Fitur utama

- API tanpa konfigurasi untuk helper response dasar.
- Kode error publik yang stabil dan bebas bahasa.
- Katalog terjemahan Bahasa Indonesia dan Inggris berbentuk JSON.
- Pesan error internal disembunyikan secara default.
- Modul utama kompatibel dengan Go 1.22+ dan hanya memakai standard library.
- Dukungan opsional untuk PostgreSQL dan `pgx/v5` tanpa menambah dependency ke modul utama.
