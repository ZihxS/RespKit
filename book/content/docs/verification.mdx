This report records checks that were run and the limits of the compatibility claims.

## Local verification

The latest recorded local run was performed on 10 October 2026 with Go 1.27.1 on macOS arm64. The core module supports Go 1.22 and later. The core tests also passed locally with Go 1.22.12.

| Check | Result | Command |
| --- | --- | --- |
| Core tests | Pass | `make test` |
| Tests with minimum supported Go version | Pass with Go 1.22.12 | `GOTOOLCHAIN=go1.22.12 go test -count=1 ./...` |
| Race detector | Pass | `make race` |
| Static analysis | Pass | `make vet` |
| Combined statement coverage for `resp` and `internal/...` | 100.0% | `make coverage` |
| Linux/amd64 and Windows/amd64 cross-build smoke | Pass; compile only | `GOOS=linux/windows GOARCH=amd64 go test -exec=true -count=1 ./...` |
| GitHub Actions workflow syntax | Pass | `actionlint .github/workflows/ci.yml` |
| Upstream framework suite with race detector | Pass; 64 tests | `go test -race -count=1 -v ./...` in `integrations/framework-tests` |
| Optional pgx mapper suite with race detector | Pass | `make integration-mappers` |

The cross-build smoke command compiles test binaries from the local macOS machine; it does not run those binaries on Linux or Windows.

## Hosted CI

All hosted CI jobs use Go 1.27.x. The [quality-gates run on 11 October 2026](https://github.com/ZihxS/RespKit/actions/runs/38072670243) passed on Ubuntu, macOS, and Windows. It also passed the upstream framework runtime tests, race detector, 100% statement-coverage gate, and optional pgx mapper tests.

An earlier workflow run exposed a macOS runner issue with Go 1.22 and a coverage gap. CI now uses one Go version across all operating systems, and regression tests cover the previously unmeasured package paths. Go 1.22 remains the supported minimum for the core module and passed its local test run.

## Pinned framework versions

The integration suite sends requests through these upstream routers:

| Framework or router | Tested version |
| --- | --- |
| Gin | v1.12.0 |
| Echo | v4.16.0 and v5.4.0 |
| Fiber | v2.52.12 and v3.0.0 |
| Chi | v5.3.2 |
| Gorilla/mux | v1.8.1 |
| Beego | v2.3.10 |

The tests check status codes, JSON bodies, localization and cache headers, error confidentiality, `Location`, and empty 204 responses. Passing the suite verifies only the pinned versions listed here.

Run the same checks with `make integration`. The framework test module and optional pgx mapper fetch upstream dependencies, so network access is required. These dependencies remain outside the core module.

## Coverage scope

The 100% figure covers combined statement coverage for the root `resp` package and runtime packages under `internal/`. It does not mean every branch or path is covered. The framework tests and pgx mapper live in separate modules and are reported independently.
