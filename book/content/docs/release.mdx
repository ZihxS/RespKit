Checklist ini membedakan pemeriksaan source lokal dari pengaturan repository dan hasil hosted CI.

## API dan keamanan

- [x] Memisahkan facade publik dari transport, localization, resolver, formatter, dan diagnostics.
- [x] Mempertahankan helper zero-config `resp.OK`, `resp.Fail`, dan helper response lain.
- [x] Menjaga key dalam `data` tetap milik aplikasi dan tidak mengubah casing.
- [x] Menyembunyikan pesan error mentah secara default; opsi debug dinyatakan berbahaya.
- [x] Menetapkan module path `github.com/ZihxS/RespKit` di seluruh repository.
- [x] Mencatat kontak keamanan maintainer: [m.saleh.solahudin@gmail.com](mailto:m.saleh.solahudin@gmail.com).

## Pengujian dan repository

- [x] Menjalankan test, race detector, vet, dan gate coverage 100% untuk `resp` + `internal/...` secara lokal.
- [x] Menjalankan test race-enabled terhadap router upstream Gin, Echo v4/v5, Fiber v2/v3, Chi, Gorilla/mux, dan Beego.
- [x] Menjalankan test adapter pgx opsional.
- [x] Menambahkan GitHub Actions untuk matriks Go dan platform, test framework upstream, serta mapper pgx.
- [ ] Memastikan workflow GitHub Actions terbaru lulus pada semua kombinasi OS/toolchain.
- [ ] Mengaktifkan Private Vulnerability Reporting dan Dependabot alerts.
- [ ] Melindungi branch default dengan pull request dan required CI checks.
- [ ] Membuat tag release `v1.0.0` setelah semua gate di atas selesai.

## Status distribusi

Source dan dokumentasi tersedia di [GitHub](https://github.com/ZihxS/RespKit) dan [GitHub Pages](https://zihxs.github.io/RespKit/). Label versi source `v1.0.0` belum berarti sudah ada GitHub release atau bahwa seluruh kombinasi versi dependency telah disertifikasi.
